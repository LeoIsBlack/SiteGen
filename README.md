# SiteGen

**Демо-сайт:** https://leoisblack.github.io/SiteGen/

Минималистичный презентационный сайт студии **SiteGen** — разработка лендингов, 5-страничных сайтов и маркетплейсов под ключ в эстетике Apple.

## Возможности

- **Примеры работ в 3 форматах** — лендинги, 5-страничные сайты и маркетплейсы с живыми интерактивными макетами (переключение цветов, навигация по 5 страницам, поиск, фильтры и корзина).
- **Адаптация под любые экраны** — ПК, планшеты, смартфоны и раскладные устройства (раскрытый dual-экран с учётом линии сгиба и узкий внешний экран).
- **Интерактивная лаборатория устройств** — наглядное переключение и анимация раскрытия раскладного экрана.
- **Плавные анимации** — фоновое световое поле на Canvas, scroll-reveal эффекты и тактильные микроанимации.
- **Прямая связь через WhatsApp** — выбор формата сайта и автоматическая подготовка сообщения.

## Структура проекта

```text
SiteGen/
├── index.html          # Основная страница
├── config.js           # Настройки бренда и номер WhatsApp
├── css/
│   └── styles.css      # Стили, анимации и адаптивная вёрстка
└── js/
    ├── projects-data.js # Данные и макеты примеров сайтов
    ├── app.js           # Интерактивная логика и анимации
    └── legal.js         # Документы: оферта, политика конфиденциальности, согласие, cookie
```

## Реквизиты и документы

В подвале сайта — контакты, реквизиты и документы (публичная оферта, политика конфиденциальности,
согласие на обработку персональных данных, сведения о cookie). Документ открывается в окне по ссылке
или по прямому адресу: `…/#offer`, `…/#privacy`, `…/#consent`, `…/#storage`.

Заполните блок `legal` в `config.js` (ИП, ИНН/ИИН, город, почта, время работы, дата редакции) и поставьте
`isPlaceholder: false`. Тексты документов — типовой шаблон: перед запуском проверьте их с юристом под свою
страну и форму бизнеса.

## Настройка номера WhatsApp

Отредактируйте `whatsappNumber` и `whatsappDisplay` в файле `config.js` — ссылки и номер на сайте обновятся автоматически.

## Локальный запуск

Проект собран на чистых HTML, CSS и JavaScript без сборки и зависимостей — достаточно открыть `index.html` в браузере или запустить любой статический сервер.
